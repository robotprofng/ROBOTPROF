# RobotProf Website

A website developed for RobotProf, an initiative helping healthcare professionals learn and apply AI in their work.

## About the Project

RobotProf focuses on practical AI education for healthcare professionals, including Python, data analysis and machine learning.

I built this website to give the initiative a clear online presence, communicate what it offers and make it easier for visitors to learn about its work.

## Features

- Clear presentation of the initiative and its focus.
- Information about its AI training for healthcare professionals.
- Responsive layout for different screen sizes.
- Simple navigation and access to information.

## Built With

- HTML
- CSS
- JavaScript

```bash

```
